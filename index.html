서버 시간

예매·수강신청 사이트의 서버 시간을 ms 단위로, 잠금 화면과 다이내믹 아일랜드에.

자주 묻는 것

사이트는 어떻게 추가하나요?
시계 위의 '+ 사이트'를 눌러 티켓예매·기차·예약·수강신청 목록에서 고르세요. 무료로는 1개까지 추가할 수 있고, 더 많은 사이트와 주소 직접 입력은 서버 시간 Pro에서 쓸 수 있습니다. 추가한 사이트 버튼을 길게 누르면 지울 수 있습니다.
서버 시간은 어떻게 재나요?
고른 사이트에 짧은 요청을 몇 번 보내, 응답에 담긴 서버 시각이 바뀌는 순간을 잡아 기기 시계와의 차이를 계산합니다. 시계 아래에 차이와 오차 범위가 함께 나옵니다.
'잴 수 없는 사이트'라고 나와요.
일부 사이트는 응답에 서버 시각을 담지 않거나 캐시된 값을 돌려주어 잴 수 없습니다. 같은 서비스의 다른 주소(예: 예매 페이지 주소)를 직접 입력해 보세요.
라이브 액티비티가 안 보여요.
설정 → 서버 시간에서 '실시간 현황'을 켠 뒤 앱을 다시 열어 주세요. 앱을 열면 자동으로 시작됩니다.
다이내믹 아일랜드에는 왜 ms가 안 나오나요?
iOS가 라이브 액티비티를 1초보다 자주 갱신하지 않아서 시:분:초까지만 보입니다. 초가 바뀌는 순간은 서버 시간에 맞춰져 있습니다. ms는 앱 화면에서 확인하세요.
빨간색 경고는 뭔가요?
매분 0초 직전 몇 초 동안 앱의 초 숫자가 빨갛게 바뀌고 매초 살짝 튑니다. 설정에서 3초·5초·10초 전 중에 고르거나 끌 수 있습니다.
목표 시각 알림은 얼마나 정확한가요?
서버 시간 기준으로 예약하지만 알림은 iOS가 보내기 때문에 1초 안팎 늦을 수 있습니다. 정확한 순간은 앱 화면과 진동으로 확인하세요. (Pro 기능)
시간이 맞지 않는 것 같아요.
시계 아래의 ↻를 눌러 다시 맞춰 주세요. 함께 보이는 오차 범위는 네트워크 상태에 따라 달라집니다.
다른 기기에서 산 Pro가 안 보여요.
같은 Apple 계정으로 로그인한 뒤 설정 → 서버 시간 Pro 구매 화면에서 '구매 복원'을 눌러 주세요.
