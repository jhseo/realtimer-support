# 서버 시간 지원 페이지

iOS 앱 **서버 시간**(Realtimer)의 지원·개인정보 처리방침 페이지.
App Store에 적는 두 주소와 앱이 받아 쓰는 사이트 목록을 띄우기 위한 저장소라 앱 소스는 들어 있지 않다.

- 지원: https://jhseo.github.io/realtimer-support/
- 개인정보 처리방침: https://jhseo.github.io/realtimer-support/privacy.html
- 사이트 목록(앱이 받아 씀): https://jhseo.github.io/realtimer-support/sites.json

`sites.json`을 고치면 앱 업데이트 없이 사이트 추가 화면의 목록이 바뀐다. 넣기 전에 그 주소의 `Date` 헤더로 서버 시간을 잴 수 있는지 확인한다.

문의: jhseo.dev@gmail.com
